# مرتب‌کننده‌ی خودکار پوشه‌ی Downloads

یک برنامه‌ی ساده‌ی ویندوزی با پایتون و PySide6 که فایل‌های پوشه‌ی Downloads را بر اساس نوع، در زیرپوشه‌ها مرتب می‌کند.

## امکانات

- مرتب‌سازی فایل‌ها در این پوشه‌ها:

  | پوشه | نوع فایل‌ها |
  |---|---|
  | `Images` | jpg, png, gif, webp, bmp, svg, ... |
  | `Videos` | mp4, mkv, avi, mov, ... |
  | `Music` | mp3, wav, flac, aac, ... |
  | `Documents` | pdf, docx, xlsx, pptx, txt, ... |
  | `Archives` | zip, rar, 7z, ... |
  | `Installers` | exe, msi |
  | `Others` | بقیه‌ی فایل‌ها |

- انتخاب پوشه‌ی دیگر به‌جای Downloads
- نمایش گزارش (لاگ) کارهای انجام‌شده
- دکمه‌ی **برگرداندن (Undo)** برای آخرین مرتب‌سازی
- **مرتب‌سازی خودکار**: پوشه را زیر نظر می‌گیرد و فایل‌های جدید را خودش جابه‌جا می‌کند
- آیکون در System Tray (کنار ساعت). با بستن پنجره، برنامه در پس‌زمینه می‌ماند.

## نکات ایمنی

- **هیچ فایلی حذف نمی‌شود**؛ فقط جابه‌جا می‌شود.
- اگر در مقصد فایلی با همان اسم باشد، روی آن نوشته نمی‌شود و شماره به اسم فایل اضافه می‌شود؛ مثلاً `report (1).pdf`.
- فایل‌های نیمه‌دانلود (`.crdownload`، `.part`، `.tmp`) دست نمی‌خورند. وقتی دانلود تمام شد و اسم فایل عوض شد، در حالت خودکار مرتب می‌شود.
- فقط فایل‌های سطح اول پوشه مرتب می‌شوند؛ زیرپوشه‌ها و محتویاتشان دست نمی‌خورند.

---

## روش ۱: اجرا با پایتون (برای شروع)

پایتون ۳.۹ یا بالاتر لازم است ([python.org](https://www.python.org/downloads/) — موقع نصب تیک **Add Python to PATH** را بزنید).

ساده‌ترین راه: روی فایل `run.bat` دوبار کلیک کنید. اولین بار خودش محیط مجازی می‌سازد و کتابخانه‌ها را نصب می‌کند.

یا دستی، در Command Prompt داخل همین پوشه:

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## روش ۲: ساخت فایل exe تکی

با این روش، برنامه بدون نصب پایتون هم اجرا می‌شود.

روی ویندوز، فایل `build_exe.bat` را دوبار کلیک کنید (یا دستی):

```bat
venv\Scripts\activate
pip install -r requirements-dev.txt
pyinstaller --noconfirm --clean --onefile --windowed --name DownloadsOrganizer main.py
```

فایل نهایی اینجا ساخته می‌شود: `dist\DownloadsOrganizer.exe`

> ⚠️ **مهم:** PyInstaller فقط برای سیستم‌عاملی که رویش اجرا می‌شود فایل می‌سازد. برای گرفتن `.exe` باید این مرحله را **روی ویندوز** انجام دهید.
> اولین اجرای exe ممکن است چند ثانیه طول بکشد (چون فایل تکی است). ممکن است آنتی‌ویروس یا SmartScreen هم برای برنامه‌های تازه‌ساخته هشدار بدهد؛ این معمول است.

## طرز استفاده

1. برنامه را باز کنید. پوشه‌ی پیش‌فرض همان Downloads شماست.
2. اگر پوشه‌ی دیگری می‌خواهید، **انتخاب پوشه...** را بزنید.
3. **مرتب کن** را بزنید. نتیجه در بخش گزارش نمایش داده می‌شود.
4. پشیمان شدید؟ **برگرداندن (Undo)** فایل‌ها را به جای اولشان برمی‌گرداند.
5. برای مرتب‌سازی دائمی، تیک **مرتب‌سازی خودکار** را بزنید.
6. پنجره را ببندید؛ برنامه کنار ساعت می‌ماند. برای باز کردن، روی آیکون کلیک کنید. برای **خروج کامل**، روی آیکون راست‌کلیک کنید و «خروج» را بزنید.

> برای اینکه برنامه با روشن شدن ویندوز خودش اجرا شود: کلیدهای `Win + R` را بزنید، `shell:startup` را تایپ کنید و یک میان‌بُر (Shortcut) از `DownloadsOrganizer.exe` داخل آن پوشه بگذارید.

## ساختار پروژه

| فایل | کار |
|---|---|
| `organizer.py` | منطق مرتب‌سازی (بدون رابط گرافیکی) |
| `main.py` | پنجره، System Tray و مرتب‌سازی خودکار (watchdog) |
| `test_organizer.py` | تست‌های خودکار (`python -m unittest`) |
| `requirements.txt` | کتابخانه‌های لازم برای اجرا |
| `requirements-dev.txt` | کتابخانه‌ها + PyInstaller |
| `run.bat` / `build_exe.bat` | اجرای سریع / ساخت exe |

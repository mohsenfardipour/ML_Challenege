# کیمیاگر — نسخهٔ دیجیتال کتاب کار ۴۵ روزه

برنامه‌ای خصوصی و آفلاین. همهٔ اطلاعات فقط روی دستگاه خود شما ذخیره می‌شود و به اینترنت فرستاده نمی‌شود.

## ۱. نصب Node.js (فقط یک بار)
1. به سایت nodejs.org بروید و نسخهٔ **LTS** را دانلود و نصب کنید (گزینه‌ها را پیش‌فرض بگذارید).
2. برنامهٔ **PowerShell** را باز کنید و بنویسید:
   ```
   node -v
   ```
   اگر عددی مثل `v22.x` دیدید، نصب درست است.

## ۲. گرفتن پروژه
اگر Git دارید:
```
git clone https://github.com/mohsenfardipour/ML_Challenege.git
cd ML_Challenege
git checkout claude/quirky-clarke-ufa7jt
cd kimiagar
```
(یا از صفحهٔ گیت‌هاب، شاخهٔ `claude/quirky-clarke-ufa7jt` را به صورت ZIP دانلود کنید، باز کنید و در PowerShell به پوشهٔ `kimiagar` بروید.)

سپس یک بار وابستگی‌ها را نصب کنید (به اینترنت نیاز دارد):
```
npm install
```

## ۳. اجرا در مرورگر (برای امتحان)
```
npm run dev
```
آدرس `http://localhost:5173` را در مرورگر باز کنید. برای بستن، در PowerShell کلیدهای `Ctrl + C` را بزنید.

## ۴. ساخت نصب‌کنندهٔ ویندوز (.exe)
```
npm run dist:win
```
بعد از چند دقیقه فایل نصب در پوشهٔ `release` ساخته می‌شود (مثلاً `Kimiagar Setup 1.0.0.exe`). آن را اجرا و برنامه را نصب کنید.
از این به بعد «کیمیاگر» را از منوی استارت باز کنید؛ **کاملاً آفلاین** کار می‌کند و دیگر نیازی به PowerShell نیست.

> اگر ویندوز هشدار «Windows protected your PC» داد، روی **More info** و سپس **Run anyway** بزنید (چون فایل امضای دیجیتال ندارد).

## ۵. اجرای آفلاین بدون نصب (اختیاری)
```
npm run build
npm run preview
```
سپس `http://localhost:4173` را باز کنید. این حالت هم بدون اینترنت کار می‌کند.

## ۶. پشتیبان‌گیری و بازگردانی
- **تنظیمات ← پشتیبان‌گیری (JSON)**: یک فایل از همهٔ اطلاعات می‌سازد. آن را در جای امن (فلش، ایمیل خودتان) نگه دارید. برنامه هر هفته یادآوری می‌کند.
- **تنظیمات ← بازگردانی از فایل…**: فایل پشتیبان را انتخاب کنید؛ تعداد روزها را نشان می‌دهد و بعد از تأیید، **همهٔ اطلاعات فعلی را جایگزین می‌کند**.
- گوشی و کامپیوتر خودکار همگام نمی‌شوند. برای انتقال: در یکی پشتیبان بگیرید و در دیگری بازگردانی کنید.
- خروجی **CSV** (برای اکسل) هم در همان بخش هست.
- اطلاعات نسخهٔ مرورگر و نسخهٔ نصب‌شده جدا از هم هستند (برای انتقال، باز هم از پشتیبان استفاده کنید).

## ۷. استفادهٔ روزانه
- **شب قبل:** صفحهٔ «امروز» ← «برنامه‌ریزی فردا»: قصد، موضوع و شرح چهار اقدام، میزان خروج از ناحیهٔ امن، نیاز/ارزش/توانایی.
- **در طول روز:** در «امروز» وضعیت اقدام‌ها و «بله/خیر» تعهدات را بزنید.
- **آخر شب:** «صفحهٔ کامل امروز»: موانع و کشف، امتیاز هر کارت، تجربهٔ امروز و حال. امتیاز امروز خودکار حساب می‌شود.
- **کپی متن روز:** برای فرستادن در تلگرام.
- همه چیز خودکار ذخیره می‌شود؛ دکمهٔ ذخیره وجود ندارد.

## ۸. ویرایش متن‌های ستاره بازنویسی
همهٔ عنوان‌ها، سؤال‌ها و توضیحات در فایل `src/config/star.json` است. آن را با Notepad باز کنید، متن‌های داخل `"question": ""` و `"instruction": ""` را بنویسید، ذخیره کنید و دوباره `npm run dist:win` را اجرا کنید.

## ۹. آزمون‌ها
```
npm test
```
آزمون‌های امتیازدهی (مثال‌های ۱۰۰ و ۷۷ و روزهای ۱۷، ۱۸، ۱۹، ۲۳)، تقویم شمسی، چرخهٔ ۱۴ روزه و پشتیبان را اجرا می‌کند.

## ۱۰. نسخهٔ اندروید (برنامهٔ بومی Kotlin)
کد اندروید در پوشهٔ `kimiagar/android` است. همان قوانین امتیازدهی، همان تقویم شمسی و **همان فایل پشتیبان** نسخهٔ ویندوز را دارد؛ پس می‌توانید پشتیبانِ ویندوز را در گوشی بازگردانی کنید و برعکس.
برنامه **اجازهٔ اینترنت ندارد** و اطلاعاتش در پشتیبان ابری گوگل هم ذخیره نمی‌شود.

### راه ساده: نصب فایل APK آماده
1. فایل `kimiagar/android/release-apk/kimiagar.apk` را به گوشی بفرستید (کابل، تلگرامِ «Saved Messages»، یا گوگل‌درایو).
2. روی گوشی فایل را باز کنید. اگر پرسید «نصب از منابع ناشناس»، برای همان برنامه (مثلاً Files یا تلگرام) اجازه بدهید.
3. «نصب» را بزنید. اگر Play Protect هشدار داد، «Install anyway» را بزنید (چون برنامه در گوگل‌پلی نیست).

### ساختن APK روی کامپیوتر خودتان (اختیاری)
1. **Android Studio** را از developer.android.com/studio نصب کنید (خودش Java و Android SDK را نصب می‌کند).
2. Android Studio ← **Open** ← پوشهٔ `kimiagar\android` را انتخاب کنید و صبر کنید تا Gradle Sync تمام شود.
3. منوی **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**. فایل در `android\app\build\outputs\apk\debug` ساخته می‌شود.
4. یا گوشی را با کابل وصل کنید (USB debugging روشن) و دکمهٔ سبز ▶ (Run) را بزنید.

### انتقال اطلاعات بین گوشی و کامپیوتر
در یکی: **تنظیمات ← پشتیبان‌گیری (JSON)**. فایل را به دستگاه دیگر ببرید و آنجا **تنظیمات ← بازگردانی از فایل…** را بزنید. توجه: بازگردانی همهٔ اطلاعات دستگاه مقصد را جایگزین می‌کند.
